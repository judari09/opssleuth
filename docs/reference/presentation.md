# presentation

Único módulo del proyecto que importa `rich` (spec 004). Etiquetas de rol
obligatorias, renderizado Markdown, indicador de actividad, y el banner de
bienvenida (con degradado automático a ASCII si la terminal no soporta los
caracteres de dibujo de caja).
